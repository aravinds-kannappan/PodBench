# Exploratory original-weight follow-up

**Exploratory (not preregistered)**

The original recovery results informed this analysis. The checkpoints, SQLite cases and pre-intervention transcripts are fixed. Each Hugging Face artifact is verified against its pinned digest in weights.json. Both models use CPU bfloat16 in Transformers, their native tokenizer's ChatML template, eager attention, and greedy decoding with the original 12-token action budget. The Q4_K_M archive uses a different inference engine and weight precision.

* Teacher-force each model's own archived turn 1, turn 2 when present and the first later decision after inspection if it was not already included. Never append the target reply to its own input. Cache identical rendered prefixes locally but count the scheduled records they represent. Record fixture, stage and class coverage.
* Extract the residual after each decoder block at the last prompt token, before final normalization. Use the model's final norm and tied unembedding on each block for a logit lens. Report the highest scoring menu action's **first token**, its margin and agreement with the final layer's restricted readout. First tokens are distinct within each menu. Earlier and intermediate candidate probabilities are not full-action probabilities; they omit later subwords, terminators and out-of-menu completions.
* Fit fixed L2 linear least-squares classifiers for prior commit state, whether any inspect action has completed, instruction arm, and the reference next action. Fit on seeds 11, 23 and 37 and test on seed 53. Refit on a fixed permutation of training labels and report the held-out majority baseline. The state-aware reference orders unfinished mutations in the fixture's declared order and then submits, omitting irreparable overapplication. It describes one canonical plan after access to ground truth. At the first turn, the hidden state is indistinguishable across the paired worlds.
* At the decision token, average attention over heads separately for the system text, the added instruction and the contents of prior tool observations. Report mass and the uniform length baseline. Only inputs containing a span contribute to its denominator. Attention mass is descriptive.
* For each held-out family/menu pair, transfer the verify-first final-position activation into the corresponding generic input, one block and one component at a time. Intervene separately on residual block output, attention output and MLP output. Preserve the generic cached prefix. Measure the change in the donor-vs-recipient first-token margin on pairs where their natural action-token rankings differ; also retain every patched result and unrestricted-vocabulary token flip. These local readouts do not amount to successful tool use.
* Estimate the blockwise verify-first minus generic mean vector on **first-decision** residuals from the three training seeds only, collapsing duplicate hidden worlds. Use the midpoint block fixed before reading outcomes, five fixed coefficients (−1, 0, +0.5, +1 and +2), with no fitting to the held-out cases. Inject the vector into the generic first decision's final prompt token once. Continue greedy generation and execute all following actions in the fresh SQLite episode with no further steering. Each coefficient uses the same 12 held-out worlds/menus per checkpoint. Record first inspection, submission, exact state and exact submitted recovery. Every condition has a five-decision budget.
* Compare original-weight greedy completions on all 12 unique first-turn texts for seed 53 per checkpoint to their archived GGUF replies. Separately compare raw HF vs GGUF vocabulary probability of the first inspect token, verifying identical token IDs and input length before comparing. Report invalid replies explicitly. Engineering differences, small sample size, correlated prefixes, and steering at a single position in a fixed block limit generalization.

On held-out family/menu pairs with **different valid natural greedy actions** under the two HF instructions, also continue each patched first token greedily through the full 12-token action budget. Record exact action-name transfer to the donor in those pairs. Keep all family/menu pairs in the token-level patch analysis. This outcome-selected localization subset is descriptive and separate from the balanced steering trial.
