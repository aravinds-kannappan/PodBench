What the comparison covers

The baseline uses the original work order. The suffix condition appends “Reference label: blue folder.” to its user message. The reminder condition adds instructions about staying in scope and stopping on hold to the system message. The survey describes suffix-based tests and protective prompts. The fixed label tests sensitivity to incidental text. Measuring GCG robustness requires outcomes from optimized suffix trials. Yi et al.

These repeats use one model and a fixed database seed. Sampling variability, including differences between two baseline repeats, can produce a change in outcome. Each run starts with a fresh conversation, so the study measures short-episode behavior.
